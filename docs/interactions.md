# Взаємодії та Жести (Interactions)

Для забезпечення якісного досвіду користувача на будь-яких пристроях, у проєкті використовуються сучасні веб-стандарти обробки вводу.

## Pointer Events API

Ми відмовилися від роздільної обробки Mouse та Touch подій на користь **Pointer Events**. 
- **Універсальність:** Один обробник (`onPointerDown`, `onPointerMove`) працює для миші, пальця та стилуса.
- **Pointer Capture:** Дозволяє "захоплювати" вказівник, щоб рух продовжував відстежуватися, навіть якщо палець або курсор вийшли за межі елемента (важливо для слайдерів та перетягування).

## Хук `useDraggable`

Для реалізації будь-якої логіки перетягування (наприклад, плаваючі вікна, кастомні слайдери) використовується універсальний хук `src/shared/lib/draggable/useDraggable.ts`.

### Ключові особливості:
- **Threshold (Поріг):** Драг починається лише після того, як вказівник змістився на 3 пікселі. Це запобігає випадковому перетягуванню при звичайному кліку.
- **Обмеження осей:** Можливість дозволити рух тільки по горизонталі (`x`), вертикалі (`y`) або в обох напрямках.
- **Lock to Viewport:** Опція, що утримує елемент всередині видимого вікна браузера.

### Приклад використання:
```tsx
const { position, handlePointerDown, isDragging } = useDraggable({
    axis: 'both',
    lockToViewport: true
});

{% raw %}
```tsx
return (
    <div 
        onPointerDown={handlePointerDown}
        style={{ transform: `translate(${position.x}px, ${position.y}px)` }}
    >
        Перетягни мене
    </div>
);

## Компонент `FloatingTrigger`

Для більшості сценаріїв (кнопки налаштувань, бургер-меню) рекомендовано використовувати **`FloatingTrigger`** замість прямого виклику хука. 

Він додає:
- Автоматичне збереження позиції в `localStorage`.
- Коректну обробку `fixed` позиціонування та `z-index`.
- Логіку прилипання до країв екрану.

Детальніше див. у [документації FloatingTrigger](./FloatingTrigger.md).

## CSS Оптимізація
Для тач-пристроїв ми використовуємо правило `@media (pointer: coarse)`, яке автоматично збільшує зони взаємодії для елементів, що використовують `useDraggable`, забезпечуючи зручність натискання пальцем.
