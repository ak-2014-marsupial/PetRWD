# Фіча ThemeSettings: Глибока Персоналізація

Фіча `ThemeSettings` — це потужний інструмент, який дозволяє користувачам (дизайнерам або кінцевим споживачам) повністю налаштовувати візуальний вигляд інтерфейсу в реальному часі.

### 1. Призначення: Гнучкість та Швидке Прототипування

* **Уточнення дизайну:** Фіча дозволяє миттєво знайти ідеальний візуальний баланс (відтінки, насиченість, контрастність) без внесення змін у код CSS.
* **Централізований конфіг:** Фінальні значення, знайдені за допомогою цього інструменту, легко переносяться в `src/app/config/appConfig.ts` для закріплення їх як стандартних для проєкту.
* **Персоналізація:** Вибір користувача зберігається в `localStorage`, що дозволяє створювати унікальний досвід для кожного відвідувача.

---

### 2. Пряма взаємодія з DOM через CSS-змінні

Фіча використовує сервіс `themeVarsService` для запису значень безпосередньо в об'єкт `style` кореневого елемента (`body`). Це перекриває стандартні значення, визначені в CSS-файлах.

Код керує набором базових змінних HSL, що визначені в `appConfig.ts`:
- **H (Hue):** `--_h` — базовий тон.
- **S (Saturation):** `--_s`, `--_acc-s`, `--_text-s`.
- **L (Lightness):** `--_l-base`, `--_acc-l`, `--_text-l`.
- **Steps:** `--_l-step` (крок для фонів шарів).

Раніше система також керувала кроками для тексту (`textSStep`, `textLStep`), але ці параметри були видалені як надлишкові для спрощення системи та покращення візуальної консистентності.

---

### 3. Архітектура фічі

- **Drawer & Form:** Користувацький інтерфейс реалізований як висувна панель (`SlidingPanel`).
- **Floating Trigger:** Для відкриття панелі у згорнутому стані використовується `FloatingTrigger`, що дозволяє вільно переміщувати кнопку налаштувань по екрану.
- **Hooks:** Логіка відокремлена в хуки `useThemeEditor` та `useThemeDrawer`.
- **Sync:** Всі зміни миттєво синхронізуються з DOM та LocalStorage.
