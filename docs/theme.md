# Детальна Реалізація Керування Темою

Цей документ розкриває технічні деталі реалізації системи тем в додатку.

## Основний Принцип: CSS-змінні

Вся система тем побудована на нативних CSS-змінних (Custom Properties). Цей підхід дозволяє змінювати візуальне оформлення всього додатку без перезавантаження сторінки та без використання JavaScript для прямого маніпулювання стилями окремих компонентів.

Основний набір змінних визначений в `src/app/styles/variables.css`.

## Керування Висотою (Viewport Height)

Проєкт використовує одиниці `dvh` для запобігання стрибкам інтерфейсу на мобільних пристроях:
- `--app-height`: замінює стандартне `100vh`, підлаштовуючись під системні панелі браузера.
- Усі компоненти (AppShell, Sidebar, Drawer) посилаються на цю змінну, що гарантує цілісність лейауту.

## Перемикання Теми (Світла/Темна)

Логіка перемикання теми базується на додаванні/видаленні класу теми (`app_light_theme` або `app_dark_theme`) до основного елемента `<body>`.

1.  **`useTheme` Hook (`src/shared/lib/theme/useTheme.ts`):**
    - Цей хук надає функцію `toggleTheme` та поточне значення теми (`theme`).
    - При виклику `toggleTheme`, хук визначає нову тему.
    - Нове значення теми записується в `localStorage`, щоб вибір користувача зберігався між сесіями.
    - Клас теми застосовується до кореневого елемента `document.body`.

## Адаптивність та Типи Введення (CSS-First)

Проєкт використовує стратегію **CSS-First** для адаптивності, що гарантує відсутність затримок при зміні вигляду. Окрім стандартних перевірок ширини екрана, ми використовуємо **Interaction Media Features**:

1.  **`@media (hover: hover)`**: Дозволяє застосовувати ефекти наведення (напр. підсвічування кнопок) тільки для пристроїв з мишею. На смартфоні ці ефекти ігноруються, що запобігає "залипанню" станів.
2.  **`@media (pointer: coarse)`**: Визначає "грубий" вказівник (палець). Це дозволяє автоматично збільшувати кнопки, відступи та зони натискання для зручності touch-користувачів.

Цей підхід робить інтерфейс "розумним" без жодного рядка JavaScript-коду для responsive-логіки.

2.  **`ThemeSwitcher` Feature (`src/features/theme-switcher`):**
    - Цей компонент використовує хук `useTheme` для отримання функції `toggleTheme`.
    - Він рендерить кнопку або перемикач, яка при кліку викликає `toggleTheme`.

3.  **CSS:**
    - В `variables.css` визначені два класи: `.app_light_theme` та `.app_dark_theme`.
    - Коли до `body` додається відповідний клас, браузер автоматично застосовує інший набір значень для тих самих CSS-змінних, миттєво змінюючи вигляд усього додатку.

## Розширені Налаштування

Для більш глибокого налаштування теми, такого як вибір основного кольору та параметрів генерації HSL, використовується окремий віджет `ThemeSettings`.

*(Детальна інформація про його роботу описана в документі [docs/ThemeSettings.md](ThemeSettings.md))*
