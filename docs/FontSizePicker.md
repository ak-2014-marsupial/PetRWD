# Фіча FontSizePicker: Керування Розміром Шрифту

Фіча `FontSizePicker` є частиною віджета `ThemeSettingsEditor` і дозволяє користувачам керувати глобальним розміром шрифту всього додатку, що покращує доступність (Accessibility).

## Принцип Роботи

1.  **Вибір користувача:** Компонент `FontSizePicker` використовує `InputRange` (повзунок), який дозволяє плавно регулювати розмір тексту в межах від 12px до 24px (згідно з `fontSize.ts`).

2.  **Динамічне оновлення:** При зміні значення, JavaScript-логіка через сервіс `fontSizeService` встановлює CSS-змінну `--font-size-base` безпосередньо на кореневий елемент `<html>`.

3.  **Масштабування через CSS:**
    - Усі розміри тексту в додатку (для `p`, `h1`, `h2` і т.д.) визначені в відносних одиницях `rem`. Оскільки `rem` розраховується відносно розміру шрифту кореневого елемента (`<html>`), миттєва зміна `--font-size-base` призводить до пропорційного та узгодженого масштабування всього тексту на сайті без перезавантаження сторінки.

Такий підхід забезпечує максимальну гнучкість для користувача та чудову продуктивність.
