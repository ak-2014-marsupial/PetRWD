# FloatingTrigger: Розумні Плаваючі Кнопки

`FloatingTrigger` — це високорівневий компонент зі `shared/ui/kit`, призначений для створення плаваючих кнопок або тригерів, які користувач може перетягувати.

## Ключові Можливості

1. **Автономна Пам'ять:** Компонент автоматично зберігає свою позицію в `localStorage`. Вам потрібно лише надати унікальний `id`.
2. **Прив'язка до Країв (Pinning):** Підтримує автоматичне "прилипання" до лівого або правого краю в'юпорту з налаштовуваним відступом.
3. **Гнучкий Рендеринг:** Використовує паттерн `renderTrigger`, що дозволяє перетворити на перетягуваний об'єкт будь-який компонент (кнопку, іконку, аватар).
4. **Синхронізація:** Через колбек `onPositionChange` може повідомляти інші компоненти (наприклад, висувні панелі) про своє поточне положення для візуального вирівнювання.

## Приклад Використання

```tsx
<FloatingTrigger
    id="unique-action-id"
    pinSide="right"
    defaultY={100}
    renderTrigger={({ onClick }) => (
        <Button onClick={onClick}>🚀</Button>
    )}
/>
```

## Параметри (Props)

| Проп | Тип | Опис |
| :--- | :--- | :--- |
| `id` | `string` | Унікальний ідентифікатор для збереження позиції. |
| `pinSide` | `'left' \| 'right'` | Край, до якого притиснута кнопка (дефолт: `right`). |
| `axis` | `'x' \| 'y' \| 'both'` | Осі перетягування (дефолт: `y`). |
| `offset` | `number` | Відступ від краю `pinSide` (дефолт: `20px`). |
| `renderTrigger` | `function` | Рендер-проп, що приймає `{ onClick }`. |
| `isVisible` | `boolean` | Керування видимістю тригера. |
| `onPositionChange`| `function` | Викликається при зміні координат. |

## Архітектурний Зв'язок

`FloatingTrigger` є обгорткою над HOC `withDraggable`, який в свою чергу використовує хук `useDraggable`. Це забезпечує ієрархію від низькорівневих подій вводу до готового до використання бізнес-компонента.
