# Система Кольорів та Рекомендації

Цей документ описує унікальну систему кольорів, що використовується в проєкті, та надає рекомендації щодо її правильного застосування.

## Філософія та Підхід

Система кольорів у цьому проєкті є **генеративною** та базується на **моделі HSL** (Hue, Saturation, Lightness). Замість того, щоб визначати статичний набір кольорів, ми визначаємо базові "настроювальні" параметри (відтінок, насиченість, яскравість), з яких потім процедурно генерується вся палітра.

Це дозволяє досягти неймовірної гнучкості. Наприклад, для зміни основного акцентного кольору всього додатку достатньо змінити лише одну змінну — відтінок (`--h`). Базові параметри для генерації (Hue, Saturation, Lightness Base, Steps) налаштовані в `src/app/config/appConfig.ts`.

## Концепція Шарів (Level) Глибини UI

Логіка номерів шарів проста: чим вищий номер шару (Level), тим темнішим і глибшим він стає у світлій темі, і навпаки — світлішим та виразнішим у темній темі. Ця інверсія відбувається автоматично, забезпечуючи правильний візуальний ефект при перемиканні тем.

**Важливо:** Шари відповідають виключно за **фони** (backgrounds). Контент (текст, рамки, акценти) є глобальним і консистентним для всієї теми.

## Структура Змінних

### Глобальні змінні (Незалежні від шару)
Ці змінні слід використовувати для контенту, щоб він виглядав однаково незалежно від того, на якій панелі або картці він знаходиться:

- `--text-primary`: Основний колір тексту.
- `--text-secondary`: Вторинний, менш контрастний колір тексту.
- `--border-color`: Колір для рамок та розділювачів (має 10% прозорості, тому адаптується до будь-якого фону).
- `--accent`: Основний акцентний колір для інтерактивних елементів.
- `--on-accent`: Колір тексту поверх акцентного фону.

### Змінні шарів (Тільки для фонів)
Для кожного з трьох шарів глибини (`X` = 1, 2, 3):

- `--layer-X-bg`: Основний фон для цього шару.
- `--layer-X-hover`: Фон при наведенні курсора.
- `--layer-X-active`: Фон при активному стані.

## Рекомендації щодо Застосування

Завжди використовуйте CSS-змінні. При стилізації нового компонента, **ніколи** не використовуйте жорстко закодовані кольори (hex, rgb). 

| Елемент / Контекст та Опис                                             | Змінна                 |
| :--------------------------------------------------------------------- | :--------------------- |
| **Фон картки/панелі** <br> *Залежить від рівня вкладеності.*           | `--layer-X-bg`         |
| **Основний текст** <br> *Заголовки, основний контент.*                 | `--text-primary`       |
| **Другорядні дані** <br> *Підписи, час, лічильники (менший контраст).* | `--text-secondary`     |
| **Елемент при наведенні** <br> *Реакція на курсор.*                   | `--layer-X-hover`      |
| **Елемент при кліку** <br> *Візуальний відгук на натискання.*          | `--layer-X-active`     |
| **Розділювач / Рамка** <br> *Лінії між повідомленнями.*                | `--border-color`       |
| **Активна кнопка / CTA** <br> *Головна дія.*                           | `--accent` (bg)        |
| **Тихий Акцент (текст/іконка)** <br> *Колір акценту для тексту.*       | `--accent` (color)     |

**Важливо:** Думайте "шарами" для фонів та "типами контенту" для всього іншого. Це забезпечує візуальну цілісність та спрощує підтримку коду.
